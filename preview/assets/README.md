# Preview assets

PNG icons are crops from the user-supplied design in `docs/design/v2/netlink-bedienpaneel.pdf`. The flat background was made transparent. No new icons were drawn. The software icon and sample profile label are crops from the latest source in `docs/design/netlink-bedienpaneel.pdf`; software/status frames are the normalized source pages in `docs/design/`.

Inter is included locally from Google Fonts under the SIL Open Font License in `OFL.txt`. The PDF contains raster designs with an invisible OCR font layer, not a usable original webfont. Inter approximates editable text in the preview.

The preview makes no external font, image or API requests. Colors and geometry match the supplied 640 × 180 screens.
