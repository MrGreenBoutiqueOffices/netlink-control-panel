# Preview assets

De PNG-pictogrammen zijn uitsneden van het door de gebruiker aangeleverde ontwerp in `docs/design/v2/netlink-bedienpaneel.pdf`. De vlakke achtergrond is transparant gemaakt. Er zijn geen nieuwe iconen getekend.

Inter is lokaal opgenomen uit Google Fonts, onder de SIL Open Font License in `OFL.txt`. De PDF bevat rasterontwerpen met een onzichtbare OCR-fontlaag, geen bruikbaar origineel webfont. Inter is de benadering voor de bewerkbare tekst in de preview.

De preview gebruikt geen externe font-, image- of API-verzoeken. Kleuren en geometrie zijn afgestemd op de aangeleverde schermen van 640 × 180 pixels.
